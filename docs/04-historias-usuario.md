# Historias de Usuario

## Autenticación

**HU-001** — Como usuario nuevo, quiero registrarme con mi nombre, email y contraseña para acceder a la plataforma.

**HU-002** — Como usuario registrado, quiero iniciar sesión y que mi sesión persista para no tener que volver a autenticarme al recargar la página.

## Negocios

**HU-003** — Como propietario, quiero crear un negocio con sus datos básicos (nombre, tipo, ubicación) para empezar a registrar cierres.

**HU-004** — Como gestor, quiero configurar qué variables se usan en las predicciones (clima, temperatura, eventos…) para adaptar el modelo a mi negocio.

## Cierres diarios

**HU-005** — Como propietario, quiero registrar el cierre de caja de cada día con el total recaudado y las condiciones del día para construir mi histórico.

**HU-006** — Como gestor, quiero importar un fichero CSV con el histórico de temporadas anteriores para no tener que introducir los datos uno a uno.

**HU-007** — Como propietario, quiero corregir un cierre ya registrado si me equivoqué al introducir los datos.

## Dashboard y análisis

**HU-008** — Como propietario, quiero ver la evolución diaria, semanal y mensual de mi caja en una gráfica para entender las tendencias de mi negocio.

**HU-009** — Como gestor, quiero ver las métricas principales (caja acumulada, media diaria, mejor y peor día) en un resumen visual.

**HU-010** — Como gestor, quiero comparar la caja con variables como el clima o el día de la semana para entender qué factores influyen más.

## Predicciones

**HU-011** — Como propietario, quiero introducir las condiciones previstas para mañana (clima, temperatura, evento) y obtener una estimación de caja para planificar el día.

**HU-012** — Como gestor, quiero ver los escenarios pesimista, medio y optimista de la predicción para tomar decisiones con margen de error conocido.

**HU-013** — Como propietario, quiero leer una explicación en lenguaje natural de por qué la previsión es esa para entender los factores sin necesidad de interpretar números.

## Exportaciones

**HU-014** — Como gestor, quiero descargar mis cierres en CSV para analizarlos en Excel.

**HU-015** — Como propietario, quiero exportar un informe completo en Markdown con métricas y predicciones para compartirlo con mi asesor.
